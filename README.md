# Financial-risk-analysis-dashboard
 1. Project Title / Headline

 📊 Financial Risk Analysis Dashboard
An interactive Power BI dashboard designed to analyze financial loan performance, identify potential credit risks, and evaluate borrower behavior through key financial indicators such as loan status, interest rates, debt-to-income ratio, and loan quality.

 2. Short Description / Purpose
The Financial Risk Analysis Dashboard is an interactive Power BI report developed to provide insights into loan performance and financial risk. The dashboard helps users analyze loan applications, funded amounts, payments received, interest rates, borrower profiles, and the distribution of good and bad loans.

The purpose of this project is to transform raw financial loan data into meaningful visual insights that can support better decision-making in credit risk assessment, loan portfolio management, and financial analysis.

 3. Tech Stack
The dashboard was built using the following tools and technologies:

 📊 Power BI Desktop – Main platform used for data analysis and dashboard development.
 📂 Power Query – Used for data cleaning, transformation, and preparation.
 🧠 DAX (Data Analysis Expressions) – Used to create calculated measures and financial KPIs.
 📈 Data Visualization – Used to create interactive charts, KPIs, slicers, and analytical reports.
 🗂️ Data Modeling – Used to organize financial loan data for efficient analysis.
 📁 Excel Dataset – Used as the primary data source.
 💾 File Format – `.pbit` Power BI Template file.

 5. Features / Highlights
 🔴 Business Problem
Financial institutions manage thousands of loan applications and need to monitor the performance and risk associated with their lending portfolio.

Raw financial data can make it difficult to quickly answer important questions such as:

How many loan applications have been received?
What is the total amount funded?
How much payment has been received?
What percentage of loans are performing well?
How many loans are categorized as risky or bad?
Which loan purposes have higher loan volumes?
How do interest rates and DTI ratios impact financial risk?
Which borrower categories or regions contribute to higher loan activity?

🎯 Goal of the Dashboard
The goal of this dashboard is to provide an interactive financial analysis tool that:
 Analyzes overall loan portfolio performance.
Identifies good and bad loans.
Monitors key financial risk indicators.
Tracks loan applications and funded amounts.
Analyzes borrower characteristics and loan purposes.
Supports financial analysts in identifying potential risk areas.
Enables data-driven decision-making through interactive visualizations.

 📊 Key Performance Indicators (KPIs)

The dashboard includes important financial metrics such as:
 1. Total Loan Applications 
   Displays the total number of loan applications received.
 2. Total Funded Amount 
   Shows the total amount of money funded through loans.
 3.  Total Amount Received 
   Tracks the total payment amount received from borrowers.
 4. Average Interest Rate 
   Measures the average interest rate across the loan portfolio.
 5. Average DTI Ratio 
   Displays the average Debt-to-Income ratio to help assess borrower financial risk.
 6.  Good Loan Applications
   Shows the number and percentage of loans classified as performing well.
 7. Bad Loan Applications
   Shows the number and percentage of loans classified as potentially risky.

 📈 Dashboard Visuals
 Loan Overview:
Provides a high-level summary of the financial loan portfolio using KPI cards and performance metrics.
